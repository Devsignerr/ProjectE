# FarmBie 예제 프로젝트 (농장 경영 + 좀비 디펜스)

> CLAUDE.md에서 옮긴 상세 규칙이다. 이 영역의 코드·에셋을 고치기 전에 읽는다. 기획 결정은 `Projects/FarmBie/결정사항.md`, 작업 단계는 Plans.md "FarmBie".

- 콘텐츠는 생성물: 씬·프리팹·스프라이트·지형·머티리얼·바닥 텍스처는 `python Projects/FarmBie/Tools/BuildFarmBie.py`(도트 아트 `FarmBieArt.py`)를 고쳐 다시 만든다. 범용 도구(SceneBuilder·HD2DArt의 FCanvas/FAtlas/WriteFlipbook·ModelBounds)는 `Tools/DemoMap`에서 가져다 쓴다
- 좌표·카메라: 거의 수직 탑뷰(피치 -70°, 시야각 30°) — 화면 위 = -Y. 캐릭터 스프라이트는 **전체 빌보드(Billboard 1)**(세로축 빌보드는 이 각도에서 납작해 보임), 1 도트 = 6cm, 피벗 = 발
- 농장 격자: 칸 100cm, 52×40, 원점 (-2600, -2000) — 밭·건물·벽·좀비 흐름장이 모두 이 격자를 쓴다 (`BuildFarmBie.py` 상수 = 게임 코드 상수)
- 로직 분담: 매 프레임 대량 처리(격자·좀비 이동·흐름장·크리스탈 감지·설치물)는 게임 모듈 `Projects/FarmBie/Source`(FarmBieGame.dll), 하루 진행·상점·UI 흐름은 Lua `Content/Scripts/FarmBie`
- 시간(FarmTime.lua, 관리자에 섞임): 하루 = 낮 6→20시(실제 8분) + 밤 20→26시(실제 3.5분 = 디펜스 제한 시간) → 잠(문 앞 상호작용 또는 새벽 2시) → 날짜 넘김·자동 저장. 수치는 `Data/FarmBie/Calendar.edata`(생성기 `FarmBieData.py`) — 스크립트 상수 금지. 하늘 모델은 18시쯤 해가 지므로 화면은 **게임 시각 → 하늘 시각**(`GetSkyHour`, Calendar Sky*)으로 바꿔 쓰고 `DayNightKeys.etable` 열쇠 시각도 하늘 시각이다
- 관리자 확장 규약: 새 모듈은 `FarmGame.lua`의 모듈 목록에 넣고, 저장할 상태는 `Save<이름>/Load<이름>` 쌍 + `SaveParts`에 이름 추가, 시간 훅 `OnNightStart`/`OnDayStart(bNewSeason)`/`OnSeasonChanged(Old)`, 상호작용은 `AddInteractable{Pos, Radius, Prompt, Act}`
- 농사(FarmInventory.lua·FarmField.lua): 물건 열쇠 = 도구/비료 행 이름 또는 `Seed|Crop:<작물>:<희귀도 0~3>`. 작물 23종·도트 틀은 `Tools/FarmBieCrops.py` CROPS 하나가 표(Crops.etable)와 그림을 함께 만든다(1 도트 = 6.25cm, 16 도트 = 칸 100cm). 흙·작물 그림은 `Scene.Create`+SpriteComponent로 즉시 만든다(흙 = 바닥에 눕힘, 작물 = 전체 빌보드 칸 가운데 +18cm). 칸 막힘 판정은 높이 0 기준 OverlapBox(지면 레이캐스트는 지붕 콜라이더에 맞는다). 난수는 `Field:Random`(저장되는 LCG)
- 경제·창(FarmEconomy.lua·FarmMenu.lua): 출하 = 상자 상호작용(고른 작물 묶음, 아니면 작물 전부) → 아침 정산(`OnDayStart`). 보부상 = `Calendar.MerchantDays` 요일 06~18시, 재고 = `MerchantStock.etable`(계절 Always + 가중치 무작위, 날짜로 정해지는 난수 — 재고는 저장). 창은 `OpenMenu`가 `Game.SetTimeScale(0)`, 입력 표 `MenuUp/Down/Left/Right/Confirm/Cancel`(플레이어 `MenuNavigation`). 새 물건 종류를 팔려면 MerchantStock 행만 더한다
- 체력·정신력(FarmVitals.lua): 정신력을 깎는 곳은 `LoseSanity(양, 이유)`, 피해는 `Damage(양, 이유)`(Guard 버프 적용), 쓰러짐은 `Collapse(이유)` → 잠 전환 → 아침 `ApplySleepRecovery`(벌칙·회복). 이동 속도는 `UpdateVitals`가 정신력 배율·Speed 버프로 매 프레임 정한다(다른 코드가 MaxWalkSpeed를 직접 쓰지 않는다). 먹기 = 고른 작물 칸 + Eat(F)
- 맵(F5): 씬마다 같은 `FarmGame.lua`(속성 `Map` = Farm|Forest → `self.MapId` — `self.Map`은 밭 격자 데이터라 이름을 섞지 말 것), 이동은 `FarmTravel.lua` 트리거 → `TravelTo` → 세션 슬롯(`FarmBie_Session`, 시각·단계 포함) + `Game.OpenScene`, 도착은 `TryResumeSession` + `Spawn_<이름>`. 다른 맵에서 잠들면 집 `Spawn_Bed`로(`OnWake`). 숲 자원 = 씬의 `Node_<종류>_<번호>`(Model/Stump/Collision 자식), 상태 `NodeState`는 저장. 여러 씬 자동 검증은 Persistent `FarmBie_AutoPlay`/`FarmBie_AutoPhase` + `Run<시나리오><단계>`
- 하우징·설치물(FarmBuild.lua, F6): 설치물 = 프리팹 `Build_<종류>`(C++ `FarmStructureComponent` — 칸·내구도·Blocks·Destroyed), Lua가 격자 점유(`Structures`)·저장을 맡고 디펜스(C++)는 컴포넌트를 읽고 `Destroyed`만 켠다 → `UpdateStructures`가 정리. 설치물 정의는 `Buildables.etable`, 크리스탈 단계 `CrystalLevels.etable`, 온실 부지는 `FarmMap.Greenhouse`. 설치물 모델은 `Tools/FarmBieBuild.py`(절차 glTF) — 상자는 `FOutBuilder.Box`(공유 `HD2DMeshKit.Box`는 면 법선이 안쪽이라 정면이 컬링됨), 색은 선형 값(sRGB로 보면 더 밝다). 해는 카메라 쪽(TimeOfDay NorthAzimuth 180 — 보이는 정면이 햇빛을 받고 그림자는 화면 위로)
- 디펜스(F7): 좀비 이동·흐름장·공격·덫·포탑·투사체는 C++ `FarmDefenseSystem`(게임 모듈 OnUpdate), 밤 계획·생성·결과는 Lua `FarmDefense.lua`. 둘은 FarmGame 엔티티의 `FarmDefenseComponent`로만 주고받는다 — Lua 입력(격자·`StaticBlocked`(생성기가 씬 콜라이더에서 계산)·`AttractTiles`·`CropTiles`+`CropRevision`·감지 반경·공격 명령 `AttackSeq` 증가), C++ 출력(`Kills`·`Alive`·`PlayerDamage` 누적(Lua가 0으로)·`CropEvents`(Lua가 비움)·`CrystalFound` …). 좀비 = 프리팹 `Zombie_<종류>`(`FarmZombieComponent`, 값은 `Zombies.etable`을 Lua가 채움), 플립북 = `SpriteBase_<Walk|Attack|Die><Side|Down>`. 밭이 바뀌면 `SyncCropTiles`. 생성은 비동기(SpawnPrefab 콜백)라 "다 잡음" 판정에 `PendingZombies`를 함께 본다. 디펜스가 아닌 자동 검증은 `bPeacefulNights`(좀비 없는 밤 — `FarmAutoPilot` DefenseScenarios 밖)
- 보스(FarmBoss.lua, F8): `Bosses.etable`(Mid 중간 3 — 10·20·30일차 돌아가며, Season 계절 4 — 30일차), 보스 = 좀비 프리팹 `Zombie_<보스>` + `Boss`·처음부터 `Alerted`(크리스탈 사냥꾼)·`AggroTime`(맞으면 잠깐 플레이어). 고유 특성 = 컴포넌트 `SummonKind/Interval/Count`(C++ → `SummonRequests` → Lua 생성)·`Aura*`(불길·치유·둔화). 보스 밤 길이 `BossRules.BossNightMul`, 패배는 `OnBossNightEnd`(중간 = `bForceCollapse` → 잠이 Collapse, 계절 = 소지금·정신력)
- 탑(FarmTower.lua, F9): 탑 씬(`Map = Tower`) 방 하나를 층마다 다시 꾸민다(`TowerPresets.etable` — '#' 기둥 'B' 상자 'e' 적 자리, 입구 7칸 안은 적 없음). 적 이동은 같은 C++ 디펜스(흐름장 목표 = 플레이어 칸 `AttractTiles` 0.25초 갱신, `StaticBlocked` = 배치). 수호자 5층마다 = 체크포인트(`TowerCheckpoint`, 저장). 진행 중 런은 세션 `TowerRun`(층·전리품)으로 넘어가고, 쓰러지면 `TowerDefeat`(전리품 `LootLossOnDown`). 던전 에셋은 KayKit Dungeon(CC0, Sample에서 복사)
- 스프라이트 번쩍임: C++에서 `SpriteComponent.FlashColor`를 매 프레임 쓰면 번쩍임이 남고 같은 엔티티 그림자까지 바래 보였다 → 좀비·플레이어 피격은 `Color` 곱하기(붉게). 엔진 조사 항목은 Plans.md
- 자동 검증 규약: 시나리오가 끝나면 `Properties.AutoPlay`를 비운다(남은 프레임 동안 맵 이동으로 시나리오가 다시 시작되지 않게)
- 자동 검증: `.\Scripts\Verify.ps1 -Target Runtime -Config Release -Frames N -ExtraArgs "--project Projects/FarmBie --scene Scenes/Tests/<씬>.escene --fixed-delta 60 --no-vsync"(FarmBie 설정은 VSync 켬 — 화면이 꺼져 있으면 숨긴 창 Present가 7fps로 막힌다)` → 로그 `[FarmBie] 결과: 실패 0건`. `FarmAutoPlay`(N 1500 — 이동·플립북·구르기·카메라·충돌), `FarmTime`(N 2400 — 시계 속도·밤·등불·잠·저장·계절 경고/넘김·불러오기·연도), `FarmDefense`(N 14000 — 예고·생성·포탑·덫·작물/처치·검·활·밤 정리·잠), `FarmDefenseLoss`(피해·쓰러짐·부활·크리스탈 발견·시간 초과·부재 정산), `FarmGameOver`(크리스탈 파괴·저장 삭제), `FarmBoss`(중간 보스 등장·크리스탈로·어그로·처치 보상·패배 쓰러짐), `FarmSeasonBoss`(30일차 보스 둘·소환·계절 보스 처치 씨앗·중간 패배), `FarmTower`(씬 3번 — 입장·추격·정리·보물·계단·수호자·체크포인트·쓰러짐 전리품·재입장), `FarmBuild`(N 9000 — 건설·방향·문 통과·덫·지뢰·포탑·철거·수리·부서짐·크리스탈 옮기기/강화·온실·저장), `FarmForest`(N 9000 — 숲 왕복·나무/바위 캐기·줍기·먹기·숲 새벽 잠 → 집·3일 뒤 다시 자람), `FarmSanity`(N 6000 — 먹기·버프·정신력 낮음 속도·잠 회복·정신력 0 쓰러짐·저장), `FarmEconomy`(N 6000 — 출하·정산·보부상 요일·재고·사기·돈 부족·품절·떠남·재고 저장·소지품 옮기기), `FarmFarming`(N 6000 — 갈기·물·심기·비료·제철 거절·물 준 날만 자람·수확·다시 열림·희귀/전용 씨앗 확률·우물·저장·계절 사멸·걷기). 확인용 시각별 화면: `BuildFarmBie.py --views` → `Scenes/_FarmShot<시각>.escene`·`_FarmFieldShot.escene`(커밋 안 함)
