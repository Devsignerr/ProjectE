# FarmBie 기획 결정 사항 (2026-10-06 질의응답)

원본 기획: `기획서.txt`

## 기본
- 새 프로젝트(`Projects/FarmBie/` .eproject). HD2D 데모 시스템(인벤토리·상점·대화·저장)은 가져와 재사용
- 싱글 전용, **무한 생존**(엔딩 없음), 해마다 같은 1년 구성 반복
- 첫 구현 범위: **1년(4계절) 전체**
- 카메라: 거의 수직 탑뷰 70°+, HD-2D(2D 스프라이트 + 3D 배경)
- 아트: 무료 에셋으로 구성, 이후 교체 예정
- 저장: 취침 시 자동 저장(슬롯 3)
- 스토리: 배경 설정 + 보부상 대사만

## 시간 구조
- 하루 = 1라운드: 낮 8분(농사·채집·탑) + 밤 3~4분(디펜스 전용, 농사·상점 불가)
- 계절 = 30일. 10·20일차 중간 보스, 30일차 중간 + 계절 보스
- 요일: 보부상 방문(주 2회 고정)에만 쓴다
- 좀비는 고정 시각에 출현. 플레이어가 늦으면 늦게 합류하고, 안 오면 플레이어 없이 설치물만으로 수비

## 씨앗·작물
- 희귀도: 일반 → 레어 → 유니크 → 레전더리(기본 씨앗 = 일반)
- 희귀 씨앗: 같은 종 상위 단계 + 낮은 확률로 전용 희귀종(둘 다)
- 확률 보정: 비료만
- 판매가 배율: ×1 / ×3 / ×10 / ×40, 고정가
- 희귀 작물 용도: 비싸게 판매 / 섭취 버프 / **작물별 고유 함정·탄약 제작 재료**
- 톤: 크툴루 + 좀비 혼합(눈알 열매, 뇌 호박 등), 계절당 4~5종
- 농사: 갈기·심기·물·수확 + 비료, 다회 수확 작물 일부
- 씨앗 보충: 보부상 구매 + 수확 시 일부 회수
- 계절 전환: 경고 + 온실 예외(온실 작물은 생존)

## 경제·보부상
- 출하 상자: 다음 날 아침 정산, 밤에 안전
- 보부상 1명, 주 2회 고정 요일, 돈으로만 거래
- 재고: 고정 목록 + 무작위 일부, 방문마다 리셋

## 정신력
- 감소: 패배·쓰러짐, 밤 전투 중 사망
- 낮을 때: 능력치 감소
- 0: 쓰러짐(소지금 20% + 다음 날 늦게 기상)
- 회복: 정신력 음식(주) + 수면(소량)

## 디펜스
- **크리스탈**: 파괴 = 게임 오버. 낮에 자유롭게 옮길 수 있음. 업그레이드(체력·감지 반경 축소 등)
- 좀비: 가장자리 여러 곳에서 진입(매일 밤 다름, 낮에 예고) → 작물·구조물을 부수며 전진 → 크리스탈 감지 반경에 들어오면 크리스탈로 돌진 + 주변 좀비 호출(발견 연쇄)
- **라운드 패배 = 제한 시간(밤 길이) 안에 적을 전멸시키지 못함**
  - 일반 웨이브: 남은 좀비가 아침까지 피해만 입힘
  - 중간 보스: 소지금 20% + 쓰러짐(다음 날 늦게 기상), 보스는 떠남
  - 계절 보스: 소지금 35% + 정신력 감소(늦게 기상 없음)
- 밤 전투 중 사망: 정신력 감소 + 10초 뒤 부활(모든 밤 전투)
- 전투: 직접 전투(근접 농기구·도끼·칼 / 원거리 활·산탄총) + 설치물
- 설치물: 지뢰·가시덫·포탑(미끼·둔화 덫 없음), 내구도 있고 낮에 재료로 수리
- 하우징: 고정 건물(집·창고·온실 등) 업그레이드 + 격자 자유 배치 벽·문, 재료는 나무 → 돌 → 철
- 좀비: 기본 4종(일반·빠른·탱커·자폭) + 계절별 변종 1종

## 보스
- 모든 보스: 크리스탈 사냥(플레이어를 먼저 공격하지 않음) + 고유 특성(파괴·소환/지원·배회 작물 파괴 조합)
- 공격하면 잠깐 동안만 어그로를 끌 수 있음(강해서 오래 유지 불가)
- 포획 없음
- 계절 보스 보상: 다음 계절 전용 희귀 씨앗 + 재료

## 숲·탑(던전)
- 숲: 안전, 나무·돌·섬유·약초/버섯
- 탑: 20층, 방 프리셋 안에서 무작위 배치, 탑 안에서도 시간이 흐름, 올라갈수록 보상과 적이 강해짐
  - 5층마다 수호자 보스 + 체크포인트
  - 보상: 희귀 씨앗, 크리스탈 업그레이드 재료, 무기·장비, 고급 재료(철 등)
  - 쓰러지면 전리품 일부를 잃고 귀환
- 성장: 레벨 없음. 장비·시설·크리스탈로만 성장
