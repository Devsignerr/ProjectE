# 2D 에디터와 2D 에셋 편집기

> CLAUDE.md에서 옮긴 상세 규칙이다. 이 영역의 코드·에셋을 고치기 전에 읽는다. 규칙을 바꾸거나 더할 때는 이 문서(또는 관련 머리 주석)를 고치고 CLAUDE.md 요약 줄도 맞춘다.

- 2D 에디터(Phase 56-5a, `Editor/Editor2D/` — 순수 로직 `Editor2DMath.h` 머리 주석이 기준, 테스트 `Editor2D_*`(EditorTests)): **뷰포트 2D 모드** = 툴바 "2D"(`FViewportPanel::Set2DMode`, 상태는 `FViewport2DCamera` — `EditorCamera.json`에 `Viewport2D` + 되살릴 3D 카메라 `Saved3D`): 편집 카메라를 직교·회전 없음·+Y(Y = 5000)에서 -Y로 고정(매 프레임 `Enforce`), 휠 = 커서 기준 줌(`ZoomAroundCursor`), 가운데/오른쪽 드래그 = 팬, F = 선택 2D 경계 맞춤(`FitBounds`) — 2D 중에는 `FFlyCameraController`를 부르지 않고 원근/직교 토글은 꺼진다, 조작은 `Context.Camera == EditCamera`일 때만(플레이 중 게임 카메라 규칙 그대로). 격자 = `FEditorGrid::bPlaneXZ`(`Grid.hlsl` PlaneMode 1: 칸 = 선택 타일맵 셀(원점 = 타일맵 위치) 또는 스냅 팝업 "2D 격자", 주 격자 = 칸 × 8, 도트 격자 = 타일 px/스프라이트 텍셀 — 칸이 화면 10px 넘을 때만, 축선 Z = 0 빨강·X = 0 파랑, 거리 페이드 없음). 기즈모 = 평면 제약(이동 X/Z, 회전 Y = 2D 각, 스케일 X/Z), 2D 이동 스냅(스냅 팝업: 격자 칸 = 엔티티 위치를 월드 칸 배수로 / 픽셀 = 스프라이트 사각형 왼쪽 아래를 월드 도트 배수로 — 절대 위치, Ctrl = 일시 해제). **클릭 선택**은 기존 `PickEntity`에 통합(`Editor2DScene::Pick`): 보이는 스프라이트 사각형(`SpriteMath::ComputeQuad` — 피벗·크기·반전, 투명 픽셀 포함)·칠한 타일맵 칸·2D 콜라이더/이동기만 있는 엔티티(뒤 순위), 앞뒤 = `FindFrontmost`(정렬 레이어 → 순번 → 광선 거리 → 목록 앞 — 렌더러 정렬과 같은 관계), 2D 모드면 메시보다 우선·아니면 광선 거리 비교. 선택 맞춤 경계도 `Editor2DScene::AddBounds`(메시 없는 엔티티). **충돌 외곽선**(`FCollider2DOverlay`, ImGui 오버레이 — 깊이 무시): 선택 엔티티(툴바 다각형 버튼 / `--show-colliders-2d` = 전부)의 2D 콜라이더(`Collider2DShapes` — 물리 `BuildDesc`와 같은 스케일·각 규칙을 바꾸면 함께), 트리거 흐리게, 원웨이 위 화살표, 타일맵 충돌(`TilemapCollision::BuildShapes` 외곽선·다각형·원웨이 윗변 + 화살표, Revision·타일셋·셀 크기가 바뀔 때만 다시), 2D 관절(앵커 +, 대상 선, 회전 원, 미닫이/바퀴 축), 2D 이동기 캡슐, 3D 콜라이더(상자·구·캡슐 — 월드 행렬 근사). **타일 칠하기**(창 "타일 팔레트" `FTilePalettePanel`, 기본 배치 아래 탭): 대상 = 주 선택(없으면 첫 선택)의 타일맵(없으면 안내), 팔레트 = 타일셋 이미지 격자(에셋 편집기처럼 이미지를 CPU로 읽은 **패널 소유 UNORM 텍스처** — `LoadTexture`의 sRGB는 UNORM 백버퍼에서 어둡게 보임, 점 필터 타일셋은 `BeginNearestSampling`) + 확대(Ctrl+휠) + 클릭/끌기로 타일 하나·사각형 스탬프(`MakeStampFromTileset` — 이미지 아래 행 = 스탬프 0행). 도구 Q 선택(칠하기 끔)/B 브러시/D 지우개/U 사각형/G 흐름 채우기(경계 = 칠한 영역 ∪ 시작 칸 + 8칸, 65536칸 넘으면 안 바꾸고 알림)/L 선/I 스포이드(브러시 중 Alt = 잠깐), Shift = 지우기, 변환 X/Y/Z = FlipX/FlipY/Rotate90 토글(스탬프 배치와 칸 플래그를 함께 — `TransformStamp`/`ComposeTileFlags`), 단축키는 뷰포트/팔레트 위·Ctrl·우클릭 없을 때만. 도구가 켜지면 뷰포트 좌클릭은 `ToolOverlay`가 가져간다(타일 도구가 지형/폴리지보다 먼저). **Undo는 스트로크 끝에만**: 끄는 동안 `Runtime.Data` + `MarkTilemapEdited`(렌더러·충돌 즉시 반영), 뗄 때 `CommitTilemapData` + `MarkEdited("타일 칠하기")`(끄는 도중 MarkEdited 금지 — 지형 도구 규칙), 플레이 중·빙의 중 막힘. 미리보기 = 반투명 실제 타일(`FSceneRenderer::SetSpriteDrawList` — 앱 그리기 목록, 맨 위 레이어, 셀 변환은 `SpriteTiles`와 같은 축 행렬) + 칸 외곽선, 안 쓴 프레임은 `FinishFrame`이 비운다. **끌어다 놓기·만들기**: 콘텐츠 브라우저 `.esprite` → SpriteComponent(첫 슬라이스), `.eflipbook` → Sprite(플립북 아틀라스) + Flipbook, `.etileset` → 빈 Tilemap(셀 크기 0 = 자동) — 놓는 자리 = 커서 광선 ↔ Y = 0 평면(평행하면 기존 위치의 깊이만 0), 여러 개는 +X로 150cm씩. 엔티티 메뉴/계층 우클릭 "2D" → 스프라이트/타일맵/카메라(직교, Y = 2000에서 -Y, `Editor2DScene::CreateFromMenu` — 편집 카메라 시선이 Y = 0에 닿는 곳). 자동 검증 `--viewport-2d`(2D로 시작 + 3프레임 뒤 선택 맞춤, 선택 없으면 씬 2D 전체 `FrameAll2D`, 이 실행은 편집 카메라를 저장하지 않음), `--show-colliders-2d`, `--tile-tool brush|eraser|rect|flood|line|picker`(팔레트 앞으로), `--tile-preview-cell X,Y`(마우스 대신 미리보기 칸), `--verify-tile-paint`(선택/첫 타일맵에 브러시 선·회전 스탬프 사각형·지우개 스트로크 → 스트로크당 Undo 1단계·끄는 중 커밋 없음·Undo 3번 = 처음·Redo 3번 = 칠한 결과, 저장 안 함, 로그 `타일 칠하기 검증 통과`). 화면 확인 `-ExtraArgs "--scene Scenes/Tests/Tilemap2D.escene --viewport-2d --select Tilemap --show-colliders-2d --tile-tool brush --tile-preview-cell 2,3"`. **박스 선택**(2D·3D 공통, `FViewportPanel::CollectBoxSelection/BoxSelect`, 순수 판정 `Editor2DMath` "박스 선택" — 테스트 `Editor2D_BoxSelect*`): 기즈모·편집 도구(타일/지형 브러시가 켜져 `ToolOverlay`가 가져가면 안 함)·툴바·게임 UI가 아닌 빈 곳 왼쪽 끌기(4px 넘게) → 사각형, 그냥 = 교체(빈 사각형 = 해제), Shift = 추가, Ctrl = 토글, `Context.SelectMany`(선택은 Undo 단계 아님). 판정 = 화면 경계(월드 경계 8꼭짓점 투영, 카메라 뒤 꼭짓점 버림)가 사각형 안에 **완전히** 들어감(걸치기면 넓은 타일맵·바닥이 늘 잡힘) — 대상 = 보이는 메시(모델 하위 노드는 모델 루트로 합쳐서)·`Editor2DScene::AddBounds`(스프라이트 사각형·칠한 타일맵·2D 콜라이더, 숨긴 스프라이트 제외), 지형 제외. 9-슬라이스 스프라이트의 클릭/박스 사각형은 늘인 크기 그대로 = 렌더러가 그리는 바깥 크기(`SpriteMath::ComputeSize`, `Editor2D_NineSliceQuadMatchesDrawnSize`). 2D 회전 기즈모(`ROTATE_Y`)를 화면 반시계로 끌면 2D 각(`Physics2DMath::AngleFromRotation`)이 같은 만큼 늘고 스프라이트도 화면 반시계로 돈다(자동 검증으로 확인, 고칠 것 없음). 자동 검증 `--verify-2d-create`(40프레임: 2D 모드 → 이미지 가운데에 `.esprite/.eflipbook/.etileset` 드롭 = 엔티티 3개·컴포넌트·Y = 0·+X 150cm 간격·Undo 한 단계 → 박스 선택 교체/Ctrl 토글 → Undo/Redo → 메뉴 2D 스프라이트/타일맵/카메라 각 Undo 한 단계·화면 가운데 → 메뉴 것 Undo, 로그 `2D 만들기 검증 통과`), `--verify-gizmo-2d`(30프레임부터: 선택(없으면 첫 루트 스프라이트)에 맞춤 + 회전 도구 → ImGui 마우스 이벤트(`IO.AddMousePosEvent/AddMouseButtonEvent`, BeginFrame 전)로 고리를 찾아(`ImGuizmo::IsOver`는 직전 프레임 판정이라 프로브마다 3프레임) 반시계 60도 끌기 → 화면 각·2D 각 +60 ±4, 로그 `2D 기즈모 회전 검증 통과`) — `--verify-box-select-2d`(30프레임부터: 2D 모드 + `FrameAll2D` → 화면 경계가 가장 가까운 루트 스프라이트 둘을 감싸는 사각형을 ImGui 마우스로 끌어 교체 선택 = `CollectBoxSelection(같은 사각형)` → Ctrl 누르고 다시 끌어 0개, 로그 `2D 박스 선택(마우스) 검증 통과`) — 셋 다 씬·편집 카메라를 저장하지 않는다

- 2D 에셋 편집기(Phase 56-5b, `Editor/AssetEditors/SpriteAtlasEditor`·`FlipbookEditor`·`TilesetEditor`, 공통 `Sprite2DEditorBase`·`Sprite2DCanvas`, 순수 로직 `Sprite2DEditing`, 만들기 `Sprite2DAssetCreation`): `.esprite/.eflipbook/.etileset`를 `FAssetEditorManager` `CreateEditor`/`CanOpen`에 등록. 기반은 `FDataEditorBase`(디스크 쓰기 시각 감시 — 저장 안 한 변경이 없으면 다시 읽고, 있으면 알림 띠) + `FSprite2DLibrary` 세대 변경 알림(`OnSprite2DLibraryChanged` — 플립북이 대상 아틀라스를 다시 읽음). **편집 중에는 라이브러리를 고치지 않는다**(씬 컴포넌트는 저장된 파일만 본다 — 예외는 아래 "씬에 실시간 반영"을 켰을 때뿐) — 저장 = `FSprite2DLibrary::Save*`(디스크 + 그 경로 `Invalidate` → 사용 중 컴포넌트가 다시 해석), 저장 안 하고 닫으면 파일 상태 그대로(편집했으면 닫을 때 한 번 더 `Invalidate`). 슬라이스/프레임/다각형/타일 정의 구조 변경은 `Sprite2DEditing`(픽셀 스냅·정규화·이름 고유 `<이름>_<번호>`·격자 자르기 빈 칸 건너뛰기·프레임 이동 시 이벤트 프레임 번호 따라감·다각형 경고)을 거치고 바꾸면 `Sprite2DEditing_*`/`Sprite2DAssetCreation_*` 테스트. 텍스처 미리보기는 이미지를 CPU로 읽어(`FFileSystem` + `FImageLoader` — 빈 칸 판정·`TextureWidth/Height` 자동 채움 겸용) **편집기 소유 UNORM 텍스처**(`CreateTexture`, 밉 1개 — ImGui는 UNORM 백버퍼라 sRGB 텍스처는 어둡게 보임, 닫을 때 `DestroyTexture`)로 올리고, 점 필터 확대는 `FImGuiLayer::BeginNearestSampling/EndNearestSampling`(백엔드 표준 최근접 콜백 + 루트 시그니처가 바뀌므로 투영 상수 다시 올림, 메인 뷰포트 기준). 캔버스 공통 조작: 휠 = 확대(정수 배율 단계), 가운데/오른쪽 끌기·Space+왼쪽 = 이동, F = 맞춤. **슬라이스 이름 변경 전파**: 아틀라스 저장 때 저장본 대비 이름 변경(`Sprite2DEditing::DetectSliceRenames` — 슬라이스에 ID가 없어 같은 사각형끼리, 남은 것이 하나씩이면 그 둘)이 있으면 "참조도 바꿀까요?" 확인(자동 검증은 예) → `SpriteSliceRename::Propagate`가 Content 전체 `.eflipbook`(Frames[].Slice — `FFlipbookAsset::ToJsonString`으로 다시 씀 + 라이브러리 Invalidate)·`.escene`/`.eprefab`(모든 `SpriteComponent`의 Sprite가 그 아틀라스면 Slice — 키 순서 유지 들여쓰기 2, 프리팹은 `Context.ChangePrefab` 안에서)를 고치고, 열린 씬은 파일 대신 메모리 + `MarkEdited`(Undo 한 단계, 플레이 중이면 건너뜀 — 열린 씬 파일은 `Context.GetScenePath`로 구분), 바꾼 파일은 로그 `[슬라이스 이름 변경]`·알림. 순수 치환은 `RenameSliceRefsInFlipbook/EntityJson`(테스트 `Sprite2DEditing_SliceRename*`). **씬에 실시간 반영**(아틀라스·플립북 도구 줄, 기본 끔 — `FSprite2DEditorBase`): 상태가 바뀔 때마다 `FSprite2DLibrary::SetSpritePreview/SetFlipbookPreview`로 캐시 항목을 저장 안 한 사본으로 바꾸고(파일 그대로), 끄거나 닫으면 `Invalidate(경로)` = 파일 상태. 자기 미리보기로 오른 세대는 변경 알림으로 보지 않는다. 격자 대화 기본값 = 슬라이스가 있으면 가장 흔한 크기(`EstimateGridCellSize`, 여백·간격 그대로), 없으면 이미지 투명 열/행 패턴으로 셀·여백·간격(`EstimateGridFromImage` — 간격 1~16·여백 0~16, 큰 간격(내용에 꼭 맞는 칸) → 대칭 여백 → 작은 주기, 칸 안 투명 여백은 간격으로 봄, 간격 0 시트는 구별 불가라 텍스처를 나누는 16 → 32 → 8 + 여백·간격 0). 콘텐츠 브라우저: 이미지 우클릭 "스프라이트 아틀라스 만들기"(전체 1 슬라이스 / 격자로 자르기 대화 — `FSpriteAtlasEditor::RequestGridDialog`)·"타일셋 만들기"(타일 크기), 빈 곳 "새 플립북". 검증 `--open-asset Sprites/Samples/SampleAtlas.esprite [--sprite-select <슬라이스>] [--sprite-grid-dialog] [--verify-sprite-roundtrip]`, `.eflipbook [--flipbook-time <초>] [--verify-flipbook-roundtrip]`, `.etileset [--tileset-select <Id,...>] [--verify-tileset-roundtrip]`, `--sprite-live-preview`(열 때 실시간 반영 켬 — 왕복에서 "편집 = 라이브러리 상태", "되돌리고 끔 = 파일 상태"도 확인), 에디터 `--verify-slice-rename`(임시 복사본 `Content/__VerifySliceRename`으로 플립북·씬·프리팹·열린 씬 전파 + Undo, 끝나면 지움) — 왕복 = 20프레임째 프로그램 편집 → 실행 취소 끝까지 = 처음 → 다시 실행 = 편집 → 저장 안 함 닫기(`RevertToSaved`) = 처음 + 파일 바이트 불변(로그 `[2D 편집기 왕복]`, 실패는 Error). 숨긴 창 스크린샷은 `--asset-window 0,0,1500,820` + 가벼운 씬(`--scene Scenes/Tests/Tilemap2D.escene`)
