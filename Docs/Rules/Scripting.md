# 스크립팅 (Lua)

> CLAUDE.md에서 옮긴 상세 규칙이다. 이 영역의 코드·에셋을 고치기 전에 읽는다. 규칙을 바꾸거나 더할 때는 이 문서(또는 관련 머리 주석)를 고치고 CLAUDE.md 요약 줄도 맞춘다.

- 스크립팅(Lua 5.4 + sol2): `FScriptSystem`이 `FScriptComponent`(ScriptAsset + PropertyOverrides JSON)를 실행한다. 스크립트는 `Properties` 기본값을 가진 클래스 테이블을 반환하고 `OnStart/OnUpdate(dt)/OnDestroy`를 정의한다. 엔진 API는 리플렉션 자동 바인딩(`entity:GetComponent("TransformComponent").Position`) + 트랜스폼 빠른 경로 + `Scene/Log/Input/Time`. sol 헤더는 Scripting 모듈 내부(`LuaRuntime.h`, `SolInclude.h`)에서만 포함한다. 바인딩에서 오류는 C++ 예외(`std::runtime_error`)로 던지면 Lua 오류가 되고(Lua는 C++로 컴파일), 스크립트 오류는 해당 인스턴스만 멈춘다. 엔티티 파괴는 `Destroy()`로 프레임 끝에 지연 적용. 새 컴포넌트는 리플렉션 등록만 하면 스크립트에서 바로 쓸 수 있다. 멀티플레이: `ExecutionLocation`(ServerOnly 기본/ClientOnly/Both)로 도는 곳을 정하고, 네트워크 정보는 `FScriptNetHooks`(`FGameWorld::BeginPlay(Scene, ENetMode)`가 연결)로만 받는다 — Lua `Net.IsServer/IsClient/GetMode/GetLocalPlayerId`, `entity:GetOwner/IsLocallyOwned`, RPC `entity:CallServer/CallClient/CallMulticast("이름", ...)` → 받는 쪽 스크립트의 `Server_/Client_/Multicast_이름`(서버 RPC는 소유자만, 라우팅은 `FGameWorld`). 앱은 `FNetDriver::OnGameMessage`를 복제 객체 → `FGameWorld::HandleNetMessage` 순서로 넘긴다. 서버에서 Lua `Input`은 그 엔티티(또는 복제 조상) 소유 플레이어의 입력(클라이언트가 매 틱 보냄), 서버 스크립트는 `OnPlayerJoined(id, pawn)`/`OnPlayerLeft(id)`를 받는다(앱이 `FGameWorld::OnPlayerJoined/Left` 호출)

- 스크립트 편의(Phase 41): Lua `Timer.After/Every/Cancel/IsActive`, `Coroutine.Start/Stop/IsRunning` + 코루틴 안 `Wait(초)`(0/없음 = 다음 프레임)/`WaitFrames`/`WaitUntil`. 타이머·코루틴은 실행 중인 스크립트 인스턴스 소유이므로 **인스턴스 코드를 부르는 새 경로에는 `FLuaRuntime::FInstanceScope`를 건다**(밖에서 부르면 오류). 정리 시점(OnDestroy·파괴·스크립트 변경·핫 리로드·EndPlay)과 발사 위치(모든 OnUpdate 뒤, 노티파이/UI/시퀀스 이벤트 전, 스크립트 시간 = 게임 시간 배율 적용)는 `Scripting/ScriptTimerBindings.cpp` 머리 주석이 기준. 실제 시간 경로: `Timer.After/Every(초, 함수, { Unscaled = true })`, 코루틴 `WaitUnscaled(초)`, `Time.UnscaledDeltaTime/UnscaledTotalTime/TimeScale`(+ 함수 `Time.GetDelta/GetUnscaledDelta/GetTimeScale`) — `FScriptSystem::SetFrameTime(실제 dt, 배율)`을 `FGameWorld`가 Update 전에 부른다(부르지 않는 호출자는 배율 1). 프레임 기준(0초 타이머·Wait()·WaitFrames·WaitUntil)은 시간 정지 중에도 프레임마다 진행. 물리 모양 질의 `FPhysicsWorld::Overlap/Sweep`(`FPhysicsQueryShape`, 캡슐 +Z) → `FPhysicsSystem::Overlap*/SphereCast/BoxCast/CapsuleCast` → Lua `Physics.Overlap*/…Cast`(`FScriptPhysicsHooks`): 트리거 제외 + IgnoreBody(충돌 끈 쌍 포함, `FQueryBodyFilter`), cm↔m은 `FPhysicsWorld` 안에서만. 게임 모듈 물리 접근은 `IGameModule::GetPhysics()`(`GameModuleApiVersion` 9). 3D 디버그 선 `FDebugDraw::Get()`(Renderer, 엔진 DLL 전역 하나 — `DrawLine/Arrow/Box/Sphere/Capsule`, sRGB, 지속 초, 상한 32768개/업로드 1MB) + Lua `Debug.Draw*`(`FScriptDebugDrawHooks`): Tick/Clear/켜고 끄기는 `FGameWorld`(BeginPlay·EndPlay에서 비움, Resources 없으면 끔), 그리기는 앱이 씬 렌더 뒤 `FDebugDrawRenderer`(에디터 `FViewportPanel::RenderDebugDraw`, 런타임 `OnRender` 게임 UI 앞). 픽셀 아트 모드에서는 깊이 테스트 선을 그리지 않는다

- 스크립트 모듈/화면 좌표/UI 편집(Phase 45): 공용 Lua 데이터·함수는 `Script.Require("Content 기준 경로")`만(표준 require/package/dofile은 막힘, 규칙은 `Scripting/ScriptModuleBindings.cpp` 머리 주석, 바꾸면 `ScriptModule_*` 테스트) — 모듈 값은 상태 안 공유 테이블이므로 가변 상태를 두지 않는다. `Camera.WorldToScreen(pos[, uiEntity])` → x, y, bVisible / `Camera.ScreenToWorldRay(x, y[, uiEntity])`: 좌표 = 게임 UI 레이아웃 좌표(루트 캔버스, UI 배율 후), 뷰포트 = 그 UI 인스턴스의 뷰포트, 카메라 = 렌더러와 같은 `FCameraProjection::FindActiveCamera`(투영 식 `Scene/CameraProjection`, 테스트 `CameraProjection_*`), 픽셀 아트도 최종 출력 기준, 위치 계산은 `OnLateUpdate`에서. 위젯 `Position/Size`는 캔버스 자식만(점 앵커 축), `entity:CloneWidget(템플릿, 새 이름)`(자손 이름 = "새 이름.원래 이름") / `RemoveWidget` — 스크립트가 위젯 값을 쓰는 새 바인딩은 `MarkLayoutDirty`(`EditWidget`)를 부른다

- Lua 디버거(Phase 47 사이드): 코어는 `Scripting/ScriptDebugger.h`(`FScriptDebugger`, 규칙은 머리 주석이 기준 — 바꾸면 `ScriptDebuggerTests`도). 연결은 `FScriptSystem::SetDebugger`이고 에디터만 한다(런타임/서버/테스트는 디버거 없음 = 훅·오류 처리기 변화 없음). 훅은 켜진 중단점/단계 실행/일시 정지 요청이 있을 때만 걸고, 중단점만 있으면 "동적 모드"(호출/반환 이벤트로 중단점 파일 함수 안에서만 줄 이벤트) — **새 Lua 실행 경로에 줄 훅을 상시로 걸지 말 것**. 코루틴 훅을 위해 디버거가 `coroutine.create/wrap`을 교체하므로 Lua 상태 생성 직후(`RegisterBindings` 전) `Attach`하고, 코루틴을 만드는 새 C++ 코드는 Lua의 `coroutine.create`(교체된 것)를 쓴다. 인스턴스 메서드·콜백을 부르는 새 경로는 `Traceback`을 오류 처리기로 쓴다(디버거 연결 시 오류 정지 지점). 정지하면 `SetPauseHandler` → 에디터 `FEditorApplication::RunScriptDebugLoop`(Core `FApplication::RunNestedFrame`)가 UI만 그린다 — 게임/물리/스크립트 갱신, 씬을 바꾸는 메뉴/콘텐츠 브라우저는 정지 중에 그리지 않는다(계층/인스펙터는 `BeginDisabled`). 정지 중 플레이 정지/창 닫기는 `SuspendUntilNextSession` + `Continue` 후 프레임 끝에 정지, 재개 뒤 `DiscardElapsedTime`. 패널 `FScriptDebuggerPanel`(중단점/조사식은 ProjectUser 설정 섹션 "ScriptDebugger", 자동 검증은 읽고 쓰지 않고 오류 시 멈춤도 끔). 자동 검증 `--debug-script <Content 경로>:<줄> [--debug-script-condition <식>] [--debug-script-resume <프레임>(기본 60)] [--debug-script-break-on-error]` + `--play`. Win32 F10 단독은 창 메뉴로 넘기지 않는다(단계 실행 키)
