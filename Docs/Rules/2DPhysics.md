# 2D 물리 (Box2D·타일맵 충돌·2D 관절·2D 캐릭터 이동기·2D 물리 예측)

> CLAUDE.md에서 옮긴 상세 규칙이다. 이 영역의 코드·에셋을 고치기 전에 읽는다. 규칙을 바꾸거나 더할 때는 이 문서(또는 관련 머리 주석)를 고치고 CLAUDE.md 요약 줄도 맞춘다.

- 2D 물리(Phase 56-1, Box2D v3.1.1 — `Physics/Physics2D*`, 규칙 기준은 `Physics2DMath.h`·`Physics2DSystem.h` 머리 주석): 평면 = 월드 **X(오른쪽)·Z(위)**, 2D 카메라는 **+Y 쪽에서 -Y**를 본다(엔진 왼손 Z-up에서 -Y 쪽에서 +Y를 보면 오른쪽이 -X — `Physics2D_CameraLooksAlongMinusY`). 평면 좌표 `FVector2(월드 X, 월드 Z)` cm, Box2D m 변환은 `Physics2DWorld.cpp` 안에서만(Box2D 헤더도 거기만), 깊이 Y는 엔티티 값 유지, 2D 각 = 화면 반시계 + = `FQuat::FromAxisAngle(+Y, -각)`(`Physics2DMath::RotationFromAngle/AngleFromRotation`, 평면 밖 회전은 무시 + 경고 한 번). 컴포넌트 `RigidBody2D`(BodyType enum — 씬 JSON은 번호, 끝에만 추가)/`Box|Circle|Capsule|Polygon|EdgeCollider2D`(한 엔티티의 2D 콜라이더는 모두 한 바디, 스케일 X/Z 곱, 다각형·선분 점은 문자열 `"x,z; ..."` — `Physics2DMath::ParsePoints`, 오목·8점 초과는 볼록 껍질 + 경고, 닫힌 선분 4점 이상은 Box2D 체인(감는 방향 자동)), 충돌 레이어는 3D와 같은 `FCollisionLayerSettings`(category = 1<<칸, mask = 행렬 줄), 원웨이 = Box2D 사전 해결 콜백(플랫폼 로컬 +Z와 법선 60도 안 + 상대가 0.5m/s 넘게 올라오는 중이 아닐 때만 막음), 트리거는 정적 바디와 알리지 않음(3D와 같음). `FPhysics2DSystem`은 **`FGameWorld`가 소유**(`GetPhysics2D()`, 3D 물리 바로 뒤 같은 단계, `Systems.Physics` 없어도 돎, 보간은 3D를 따름, 클라이언트는 복제 동적 바디 키네마틱 — 물리 예측 중인 바디만 동적, 아래 "2D 물리 예측"), 충돌 이벤트는 3D 뒤에 같은 `DispatchCollisionEvents`로 같은 Lua/게임 모듈 콜백(점/법선 = 평면 위 월드 3D, 점 Y = 받는 엔티티 깊이). **Box2D 콜백(사전 해결)은 읽기만, 게임 코드 호출 금지**(월드는 작업 스레드 없이 Step 스레드에서 돈다). 중력 `FPhysicsSettings::Gravity2D`(프로젝트 설정 물리), 고정 스텝은 3D 설정 공유. Lua `Physics2D.Raycast/OverlapBox/OverlapCircle`(Vector3 X·Z 또는 Vector2, 결과 키 `Entity/Point/Normal/Distance/Fraction`), `entity:AddForce/AddImpulse/SetVelocity/GetVelocity/GetMass`는 2D 강체만 있으면 2D(둘 다면 3D + 경고), 게임 모듈 `GetPhysics2D()`(`GameModuleApiVersion` 11 — 현재 12). 바꾸면 `Physics2D_*`(PhysicsTests)·`Physics2DScript_*`(ScriptingTests). **타일맵 충돌**(Phase 56 연결): `bCollision` 타일맵은 `TilemapCollision::BuildShapes` 결과를 같은 엔티티 바디(강체 없으면 정적)에 더한다 — Full + 원웨이 아닌 다각형(경사) 타일 = **합집합 외곽선 닫힌 체인**(`TraceSolidOutlines`: 칸 단위 다각형의 변을 다른 꼭짓점에서 나눠 반대 변 쌍을 지우고 가장 왼쪽 꺾기로 이음 — 반 칸 경사와 Full의 부분 원웨이 다각형 = 칸마다 다각형, 동적 강체 타일맵만 예전 병합 상자 + 칸마다 다각형(체인은 질량·체인끼리 충돌 없음), 병합 상자 `Boxes/OneWayBoxes`는 다른 용도로 남김, 재질·레이어 = 컴포넌트 `Friction/Restitution/CollisionLayer`. 타일 모양은 `Runtime.Revision`(디코딩·`CommitTilemapData`마다 증가 — TileData 문자열이 복제·Undo로 바뀌어도 다시 디코딩)·타일셋 객체(경로·라이브러리 세대)·CellSize·스케일 X/Z·재질·레이어가 바뀔 때만 다시 만들고 바디도 다시 만든다(위치/각만이면 순간이동, 빈 맵 = 바디 없음, 매 프레임 비교는 판 번호 `TilemapVersion`). 정적 바디 순간이동은 닿아 있던 잠든 바디를 깨운다(`FPhysics2DWorld::SetTransform`). 바꾸면 `Tilemap2DPhysics_*`·`TilemapCollision_Outline*`·`TilemapCollision_SolidOutline*`. **2D 관절**(Phase 56 후속, 3D 관절 `ReplayOverlapRejectInNetwork`: 서버가 예측 캐릭터를 미끄러져 오는 마찰 없는 상자 앞 공중으로 순간이동 → 서버는 캐릭터가 먼저 내려앉아 상자를 막고, 클라이언트 상자는 ack가 오기 전 그 자리까지 와 ②가 묻힘 → 거부 후 ①, 지연 80~120ms·손실 0~10%에서 거부 8~11회, 화면 캐릭터 튐 < 25cm, 상자 들림 ≤ 서버, 서버와 수렴). 알려진 것: ①도 묻히면(가로 차이 — 이동기는 동적 바디 옆을 무시해 ①·②의 가로 결과가 같다) 그대로 쓰고 대리 캡슐이 바디를 밀어낸다(서버도 같은 자리라 결과는 수렴). 기록은 보정(`CorrectBody`)과 함께 옮겨지므로 ②가 ①과 갈리는 것은 기록 구간 안 로컬 운동(서버와 일치)이 "위에 섰는가"를 바꿀 때뿐이다. **캐릭터끼리**(`CharacterCollision` Ignore/Block/Push — 번호 끝에만 추가, 기본 Ignore = 이전 동작): 두 캐릭터 모두 Ignore가 아니어야 상호작용(대리 모양 `bSolidProxy` + 이동기 `bCollideCharacters`), 움직이는 쪽 설정이 방식 — Block = 상대 캡슐이 키네마틱 벽·바닥(위에 서면 상대 대리 속도를 발판처럼, 둥근 머리 위 접촉은 `MoveMover`가 평평한 바닥으로 풀어 미끄러지지 않음), Push = Block + 옆(|법선 Y| < 0.5)으로 막히면 못 간 만큼 × `PushStrength`(0~1, 기본 1 = 이전 동작, 작을수록 무겁게, 0 = Block) 상대를 그 캐릭터 이동 질의로 수평 이동(벽 앞에서 멈춤) 후 남은 만큼 한 번 더 — **연쇄**: 밀린 캐릭터가 그 방향 앞의 상호작용 캐릭터에 막히면 남은 거리를 그대로 넘겨 민다(밀린 쪽 설정 무관, 밀리는 캐릭터 최대 4 `MaxPushChainDepth`, 사슬에 있는 캐릭터 제외, 단계마다 접촉 순서의 첫 캐릭터 — 결정적, 세기는 처음 미는 쪽만). **밀림 저항** `PushResistance`(r ≥ 0, 기본 0 = 이전 동작): 밀리는 캐릭터는 넘겨받은 거리 ÷ (1 + r)만 받는다 — 단계마다 받는 쪽 저항으로 나누므로 사슬 끝 이동 = 처음 넘긴 거리 ÷ Π(1 + rᵢ), 한 캐릭터에서는 미는 쪽 세기 1/(1 + r)과 같은 식(`FCharacterMovement2DSystem::PushCharacter`). 미는 쪽 속도도 막혀 줄어 실제 거리는 비례보다 더 준다(세기와 같은 성질). 밟기 = 다른 캐릭터 위 착지(`EndMove` 착지 + 바닥 접촉이 캐릭터) → Lua `OnStomped(other)` + 밟힌 쪽 `OnStompedBy(other)`(착지 뒤 같은 단계, 시뮬레이션한 쪽만). 상호작용 캐릭터는 `Sync`에서 대리 바디를 상태 위치로 되돌리고(지난 스텝에 속도만큼 더 감) 무브 끝·`FollowTransform`에서 그 자리로 옮긴다 → 같은 틱 무브 순서 = 엔티티 순서. **한계**: 예측 클라이언트에서 다른 캐릭터는 스냅샷 보간(과거) 위치라 막힘·밟기가 그 기준이고 서버와 다르면 재조정이 맞춘다(보정 허용), 서버에서 밀린 캐릭터의 소유 클라이언트도 ack 재조정으로 밀린 위치를 받는다(밀기는 무브 밖 서버 일 — 같은 무브 같은 결과는 상대가 같은 자리일 때만). 바꾸면
