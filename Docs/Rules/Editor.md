# 에디터 편집기 (머티리얼 노드·데이터)

> CLAUDE.md에서 옮긴 상세 규칙이다. 이 영역의 코드·에셋을 고치기 전에 읽는다. 규칙을 바꾸거나 더할 때는 이 문서(또는 관련 머리 주석)를 고치고 CLAUDE.md 요약 줄도 맞춘다.

- 노드 머티리얼 편집기(Phase 51 사이드, `Editor/AssetEditors/MaterialEditor` + `MaterialGraphPanel` + `MaterialGraphEditing`): 그래프 구조 변경은 반드시 `MaterialGraphEditing`(순수 로직, `MaterialGraphEditorTests`)을 거친다. 패널 안 변경은 그래프 순회가 끝난 뒤 적용하고 `OnEdited(라벨, 의미 변경)`으로 알린다(위치·주석만이면 false). 편집마다 `Compile` + `Analyze`(노드 오류 = `ErrorNodes`, 출력 = `FMaterialGraphCompiler::OutputNodeId`), 공유 머티리얼 반영은 셰이더 해시가 같으면 즉시·다르면 0.2초 디바운스, 컴파일 실패면 반영 안 함. 위치 (0,0) = 위치 없음 → 열 때 `AutoLayout`(출력에서 거꾸로 열 단위). 편집기 정보(`EditorPosition`/`EditorOutputPosition`/`EditorComments`)는 해시에 영향이 없어야 한다. 인스턴스는 부모 그래프 읽기 전용 + 파라미터 덮어쓰기만. **새 노드**: `GetNodeTable`의 알맞은 `Section(범주, …)`에 넣으면 팔레트·핀·출력 이름이 자동 — 새 JSON 설정 키를 쓰는 노드만 `EMaterialNodeSetting`, `MaterialGraph.cpp` 읽기/쓰기, 패널 `DrawNodeDetails`·`MakeSummary`, 필요하면 `MaterialGraphEditing::AddNode` 기본값을 함께, 파라미터를 쓰는 노드는 `MaterialNodeSetting_Parameter` + `ParameterType`. 검증 `--open-asset <.emat,...> [--matgraph-select <Id>] [--matgraph-tab details|params|hlsl] [--matgraph-palette] [--matgraph-convert] [--verify-matgraph-roundtrip] [--verify-matgraph-edit]`

- 데이터 편집기(Phase 46-B, `Editor/AssetEditors/Data*`): 테이블/데이터 에셋/구조체 편집기는 `FDataEditorBase`(디스크 쓰기 시각 감시 + `FDataLibrary` 세대 → `OnDataLibraryChanged`로 구조체 다시 묶기)를 상속한다. 값 칸 위젯은 `DataValueWidgets::Draw` 하나를 공유(표 칸 `bCompact`, 긴 편집은 팝업) — 새 필드 타입은 여기와 `DataTableView::CompareValues/GetDefaultColumnWidth`를 함께. 보기 정렬·검색은 행 번호 목록(`DataTableView::BuildView`)만, 파일 순서는 "정렬 적용"만 바꾼다(바꾸면 `DataTableView_*` 테스트). 칸별 참조 경고는 `FDataLibrary::ValidateRecordReferences`. 구조체 저장은 이름 변경 누적 목록과 `SaveStructAndMigrate`, 저장 뒤 Undo 기록을 새로 시작. 확인 대화상자로 저장을 미루는 편집기는 `bSaveDeferred` + false. 검증 인자 `--data-select <행/필드>`, `--data-popup <필드>`, `--verify-data-roundtrip`
