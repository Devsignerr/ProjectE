# 게임 UI·다국어

> CLAUDE.md에서 옮긴 상세 규칙이다. 이 영역의 코드·에셋을 고치기 전에 읽는다. 규칙을 바꾸거나 더할 때는 이 문서(또는 관련 머리 주석)를 고치고 CLAUDE.md 요약 줄도 맞춘다.

- 게임 UI (UMG식, Phase 16): `UI` 모듈(Core만 의존, 엔진 DLL 포함) — `FUIWidget` 트리(종류별 값은 `FUIWidgetData` 한 구조체, 배치는 부모 종류별 `FUISlot`), `FUILayout::Compute`(원하는 크기 → 배치, 결과는 `State`), `FUIPainter`(→ `FUIDrawList`, 색은 sRGB 저장·그릴 때 선형), `FUIInputRouter`(맞히기 규칙 = UMG Visibility, 맞힌 위젯이 있으면 UI가 포인터를 가져감), `FUIInstance`(에셋 복제본 + 배율 + 입력). 에셋 `.eui`(`FUIAsset`, 경로는 Content 기준). 글꼴은 `FUIFontLibrary::Get()`(프로세스 전역, 동적 SDF 아틀라스 — 버전이 오르면 `FUIRenderer`가 R8 텍스처를 다시 만든다). 그리기는 `Renderer/FUIRenderer`(깊이 없음, 알파 블렌드, 묶음마다 시저). 새 위젯 종류는 `EUIWidgetType` 끝에 추가하고 `UITypes.cpp` 이름 표, `Widget.cpp`(기본값/자식 수), `UILayout.cpp`, `UIPainter.cpp`, `UIAsset.cpp`(JSON), 디자이너 팔레트/속성(`WidgetEditor.cpp`)을 함께 고친다. 레이아웃/입력 규칙을 바꾸면 `Tests/UITests`를 함께 고친다. 디자이너 자동 검증 인자 `--ui-select <위젯 이름> --ui-zoom <배율>`. 씬에서는 `FUIComponent`(`RegisterUITypes()`, 씬 로드 전 — 서버 포함)이며 런타임 상태 `FUIComponentRuntime`은 복사 시 비워진다. 프레임 순서: `FUISystem::Update`(Z 순서 큰 UI부터 입력) → 포인터를 가져가면 게임에 `FInput::WithoutMouseButtons()` → `FGameWorld::TickGameplay`(스크립트가 `OnUIClicked_<이름>` 등을 받음) → 렌더 `FUISystem::Paint` + `FUIRenderer`(런타임 백버퍼 / 에디터 플레이 뷰포트). Lua 바인딩은 `Scripting/ScriptUIBindings.cpp`(`entity:GetWidget`), C++ 게임 모듈은 `FUIComponent::Runtime`을 직접 읽는다. 그리기/맞히기는 렌더 변환까지 적용된 `State.VisualGeometry/VisualClip`(레이아웃 좌표 → `VisualScale/VisualOffset`)을 쓰고 편집(슬롯 역산)은 `State.Geometry`를 쓴다. 애니메이션은 `.eui` v2 `Animations`(`UI/UIAnimation.h`, 속성 번호는 끝에만 추가 — 파일은 이름 저장), 재생은 `FUIInstance::PlayAnimation`(기본 실제 시간, 게임 시간 옵션 `UseGameTime`은 "게임 시간 배율" 단락). 글꼴 SDF는 `UI/UISdf`(래스터 + 거리 변환 — stb_truetype SDF 함수는 CFF 3차 곡선을 버리므로 쓰지 않는다), 기본 글꼴은 `Engine/Content/Fonts/NotoSansKR-Regular.otf`. 텍스트 상자가 포커스를 가지면 `FUIInputResult::bKeyboard` → 게임에 `FInput::WithoutKeyboard()`

- 다국어(Phase 32): 문자열 표 `.estrings`(`FStringTable`, `UI/Localization.h`, 전역 `FLocalization::Get()`). 화면 글자는 `Text`를 직접 읽지 말고 `GetDisplayText/GetDisplayHintText`로 읽는다(측정·그리기·미리 굽기 공통 — 키가 있으면 그릴 때마다 현재 언어로 조회). 스크립트가 `Text/HintText`를 쓰면 키가 해제된다. pak 패키지에서는 표를 프로젝트 설정 `Localization.StringTables`에 반드시 적는다. 형식 인자 `{0}`/`{이름}`, 찾기 순서 현재 언어 → 기본 언어 → 키 그대로. 텍스트 편집 규칙은 `UI/UITextEdit.h` 머리 주석이 기준이며 `FUITextEdit`를 고치면 `TextEditTests`를 함께 고친다. 게임 UI 텍스트 입력(IME): 앱은 매 프레임 `FUIInputResult`(`bKeyboard`, `bHasTextCaret`, `TextCaret`)를 `FWindow::SetTextInput`으로 알린다(에디터는 캐럿 좌표에 뷰포트 이미지 위치를 더함). 클립보드 등 Win32 호출은 `UI/UIPlatformWindows.cpp`에만 둔다
