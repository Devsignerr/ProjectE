# Crypt2D 예제 프로젝트

> CLAUDE.md에서 옮긴 상세 규칙이다. 이 영역의 코드·에셋을 고치기 전에 읽는다. 규칙을 바꾸거나 더할 때는 이 문서(또는 관련 머리 주석)를 고치고 CLAUDE.md 요약 줄도 맞춘다.

- Crypt2D 예제(Phase 56-6, `Projects/Crypt2D/` — 던그리드식 2D 횡스크롤 로그라이트, 게임 모듈 없이 Lua, 크레딧 `CREDITS.md`): 원본 에셋(ansimuz GothicVania Church/Cemetery, CC0)은 저장소에 넣지 않고 `Projects/Crypt2D/Scripts/FetchAssets.ps1`(잠금 `Assets.json` = zip URL·MD5·푸는 파일, `ColorKeys` = 단색 바탕을 투명으로 만든 사본, `-Update`)로 `Content/Asset/GothicVania/`(gitignore)에 받는다. **스프라이트/플립북/타일셋·데이터 표·UI·프리팹·씬·`Scripts/Crypt/Rooms.lua`는 생성물** — `python Projects/Crypt2D/Tools/BuildCrypt2D.py`(받은 PNG 크기·칸을 읽음, 자체 픽셀 아트·효과음 `Crypt2DArt.py`, 방 템플릿 그리기 명령·문 규약·자동 타일 `Crypt2DRooms.py` 머리 주석이 기준)를 고쳐 다시 만든다. 규약: 1 도트 = 4cm(`UnitsPerPixel` 4), 타일 16px = 64cm, 직교 OrthoHeight 960 + `PixelArtComponent` PixelSize 3(427x240 도트 — 회전하는 무기·호 효과도 같은 도트 크기, 카메라 도트 스냅), 캐릭터 피벗 = 캡슐 중심이고 정수 도트(점 필터가 이웃 텍셀을 읽지 않게). 층 = 방 격자(5x4 칸, 칸 = 40x24 타일 템플릿)에서 시드 트리 → **큰 타일맵 하나**(지형 충돌 + 뒷벽 벽돌 + 장식 3장)에 Lua가 `SetTiles`로 조립(`Dungeon.lua` — 자동 타일 규칙은 `Crypt2DRooms.py` AutoTile과 같아야 하므로 바꾸면 둘 다, 윗면 타일 = 아래 절반 다각형·안쪽 모서리 = 오각형·발판 = Full 원웨이), 문 잠금 = 문 칸에 돌 타일. `GameManager.lua`가 한 판을 맡고 투사체·코인·효과·잔상은 스크립트 없는 `Sprite2D` 프리팹 조각을 만든 직후 콜백에서 모양을 정해 직접 움직인다(스크립트 인스턴스를 늘리지 않음), 스폰한 스크립트 엔티티는 다음 프레임 OnStart라 `GM:TakeSpawnInit`/`GetScript().Health` 같은 준비 확인 후 쓴다. 조준 = 실제 마우스 커서(`Input.GetMouseUIPosition` → `Camera.ScreenToWorldRay`, OS 커서는 숨기고(`Game.SetCursorVisible(false)`) 잠그지 않음 — 입력 모드 GameAndUI, HUD 조준점), 히트스톱 = `Game.HitStop`, 일시정지·결과 화면 = `Game.SetTimeScale(0)`(이동기·플립북까지 멈춤 — 공중에서 멈춰도 떨어지지 않는다), 피격 넉백 = `entity:AddKnockback`(적은 경직 동안 AI가 쉼, 플레이어도 짧게 튕김). 상점 방(Kind `Shop` — 생성 층의 막다른 방 하나, 진열대 3자리 = `Data/Crypt/ShopItems.etable`(회복·최대 체력·무기, 층 조건·가중치)에서 겹치지 않게, F로 코인 구매 `GM:BuyOffer`). **위 문 경로 보장**: `Crypt2DRooms.FindUpPath`가 템플릿마다 바닥 → 위 문 착지 발판까지 설 수 있는 면 그래프 경로(높이 차 ≤ 5칸·가로 틈 ≤ 4칸·단단한 단은 옆에서·머리 공간 2.5칸 — '#' 윗면은 Y + 0.5, '='는 Y + 1)를 생성 때 검사하고(없으면 오류 — 천장 아래 착지 발판은 위 문 구멍 밑에서만 오르므로 `.Plat(17, 22, 17)` 같은 발판이 필요했다) 경로를 `Rooms.lua` `UpPath`로 내보내 자동 조종이 따라간다(`AutoPilot:ClimbRoom`). 자동 검증(모두 `.\Scripts\Verify.ps1 -Target Runtime -Config Release -Frames N -ExtraArgs "--project Projects/Crypt2D --scene Scenes/Tests/<씬>.escene --fixed-delta 60"`, 로그 `[Crypt2D] 결과: 실패 0건`): `CryptAutoPlay`(N 2000 — 대시·2단 점프·원웨이 통과/내려가기·문 잠김/열림·코인·상점 구매·일시정지), `CryptBoss`(N 4000, 보스 패턴 3종·처치 → 승리 화면), `CryptFloor`(N 3000, 생성 층 탐험·전투 — 위 문도 탄다), `CryptDeath`(N 900, 체력을 낮춰 해골에게 죽음 → 사망 화면·결과 글·배율 0·커서·기록), `CryptClimb`(N 1900, 시작 + Towers/Steps/Hall 세 방을 UpPath로 오르기 + 공중 일시정지 = 떨어지지 않음), 에디터 템플릿 확인 `--scene Scenes/Tests/CryptRooms.escene --viewport-2d`. 패키징 `.\Scripts\Package.ps1 -Project Projects/Crypt2D`(매니페스트가 .esprite/.etileset 텍스처를 `pixel` 용도로 따라감, Lua가 경로를 조립하는 폴더는 `Packaging.AdditionalAssets`) 렌더 설정(`Config/Rendering.json`): 톤매핑 없음(선형 클램프)·노출 0·블룸/자동 노출/TAA/SSAO/SSR 끔·RT 끔 → 언릿 스프라이트 화면 픽셀 = 원본 PNG 색(타이틀 하늘 영역 화소 100% 팔레트 일치, ACES였을 때 0%). PSO 레시피 `Config/PipelineRecipes.epso`(타이틀·AutoPlay·Boss·Floor·Rooms·Crypt를 `--record-pso`로 기록, 패키지 Config에 포함) — 첫 실행 7.4 → 1.5s
