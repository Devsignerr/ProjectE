# 패키징·Steam·설정·콘솔·프로파일링

> CLAUDE.md에서 옮긴 상세 규칙이다. 이 영역의 코드·에셋을 고치기 전에 읽는다. 규칙을 바꾸거나 더할 때는 이 문서(또는 관련 머리 주석)를 고치고 CLAUDE.md 요약 줄도 맞춘다.

- 배포/패키징(Phase 19): **콘텐츠는 의존성 기준**(2026-10-04, Sample 11,175.5 → 5,318.9 MB): `ProjectECook --package-manifest`(규칙은 `Tools/Cook/Source/PackageManifest.h` 머리 주석 — 루트 = 게임/서버 기본 맵·플레이어 프리팹·문자열 표·Config 문자열·프로젝트 설정 `Packaging.AdditionalAssets`, 텍스트 에셋의 문자열 리터럴(이스케이프된 PropertyOverrides JSON 포함)이 Content 기준/참조 파일 폴더 기준 실제 파일이면 참조·경로 구분자 있는 실제 폴더면 하위 전체, 모델 옆 `.emeta/.eimport`, 씬 옆 `.enav`, glTF uri·`.eimport` 입력은 "모델 내부"라 패키지·단독 쿠킹 제외, 이미지 용도는 부모 체인을 해석한 `.emat` 슬롯/파라미터 용도 + 그 밖은 Color)가 `Build/Package/<프로젝트>-Manifest.txt`를 쓰고 그 모델/단독 이미지만 쿠킹하며, Package.ps1은 매니페스트 파일 + 쿠킹본만 넣는다. **코드가 경로 문자열을 통째로 조립해 여는 에셋(폴더 접두사 문자열도 없는 것)은 `Packaging.AdditionalAssets`(Content 기준 파일/폴더 ";")에 적는다**. 예전 전체 쿠킹·복사는 `-AllContent`, 스캐너를 바꾸면 `CookTests`(`PackageManifest_*`). 남은 용량은 대부분 모델 `.emodel`(4.8GB — 텍스처를 모델마다 내장해 변형 glTF끼리 중복). 패키지 배치는 `Package.ps1` 머리 주석이 기준(`<Exe>.exe` + `Engine/` + `<Exe>/` 프로젝트 폴더 — 런타임은 `--project`가 없으면 `<exe 폴더>/<exe 이름>/`에서 .eproject를 찾는다). exe는 다시 빌드하지 않고 `ProjectERuntime.exe` 복사본에 `ProjectECook --stamp-exe`(`FExecutableResources`)로 .eproject `DisplayName/Version/Company/Icon` 리소스를 쓴다(아이콘 그룹 ID 1 = 창 아이콘). `Engine/Packaged.json`이 있으면 `FPaths::IsPackaged()` → Saved는 `%LOCALAPPDATA%/[Company/]<이름>/Saved`이므로 **런타임이 쓰는 파일은 항상 `FPaths::GetSavedDirectory()` 아래**(프로젝트/설치 폴더에 쓰지 않는다). 로그는 기본 `<Saved>/Logs/<exe 이름>.log`(`--log`로 대체), 크래시·Fatal은 `<Saved>/Crashes/<시각>/`에 미니덤프 + 보고서 + 로그 사본(`FCrashHandler`, 검증 인자 `--crash-test`). Release도 PDB(`/Z7` + `/DEBUG /OPT:REF /OPT:ICF`), VC++ 런타임은 app-local(정적 CRT 금지 — DLL 경계로 STL을 넘긴다). 화면 설정은 `FGameUserSettings`(프로젝트 `Config/DefaultGameUserSettings.json` ← `<Saved>/Config/GameUserSettings.json`, 자동 검증은 사용자 파일을 읽거나 쓰지 않음, 이번 실행만 `--window-mode`): 창/테두리 없는 전체 화면(`FWindow::SetBorderlessFullscreen`, Alt+Enter), VSync. Lua `Game.Quit/GetName/GetVersion/Get·SetWindowMode/IsVSync·SetVSync`(`FScriptAppHooks` — 에디터는 Quit = 플레이 정지). 패키지 게임은 ESC로 종료하지 않는다(게임이 ESC를 받고 `Game.Quit()`). **콘텐츠 읽기는 `FFileSystem`(Core/FileSystem.h: pak → 디스크)만** — `ReadFile/ReadTextFile/Exists/GetLastWriteTime`(`ReadFileBytes`도 이것을 거친다). 새 로더에서 `std::ifstream`/`std::filesystem::exists`로 콘텐츠를 읽으면 패키지(pak)에서 깨진다. 쓰기·편집기 전용 디렉터리 탐색·glTF/FBX 원본 임포트는 디스크 직접. 패키지는 `<Exe>/Content.epak`(`FPakWriter`, `ProjectECook --make-pak`, 키 = 패키지 루트 기준 소문자 경로, 항목별 FNV 해시)을 `FPaths`가 시작 때 마운트한다. 오디오는 miniaudio VFS(`pResourceManagerVFS`)로 같은 경로를 쓴다. pak 형식을 바꾸면 `FPakWriter::Version`을 올린다

- Steam(Online 모듈, 선택): Steamworks SDK는 저장소에 넣지 않고 루트 `CMakeLocal.cmake`(gitignore)의 `set(E_STEAMWORKS_SDK_DIR ...)` 또는 환경 변수 `STEAMWORKS_SDK_DIR`로 지정한다(없으면 같은 API의 빈 구현 — `FSteamSubsystem::IsCompiledIn`). Steam 헤더는 `Online/SteamSubsystem.cpp`에서만. `FSteamSubsystem::Get()`(엔진 DLL 전역 하나)을 런타임만 .eproject `"SteamAppId"`로 **렌더러보다 먼저** Init(오버레이), 매 프레임 `RunCallbacks`, 종료 시 Shutdown — 에디터/서버는 초기화하지 않는다. 패키지 게임은 Steam 밖에서 실행되면 `SteamAPI_RestartAppIfNecessary`로 다시 실행(자동 검증·`--no-steam-restart` 제외), 개발 실행은 환경 변수 `SteamAppId`로 steam_appid.txt 없이. Steam이 꺼져 있으면 경고 후 계속. Lua `Steam.IsAvailable/GetPlayerName/GetLanguage/UnlockAchievement/IsAchievementUnlocked/ClearAchievement/ActivateOverlay/IsOverlayActive`(`FScriptSteamHooks`, `FGameWorld::Init`이 연결), 게임 모듈은 `Online/SteamSubsystem.h` 직접. SDK 1.53은 통계 수신(`RequestCurrentStats`) 전 업적 요청을 대기열에 둔다. `steam_api64.dll`은 엔진 DLL 빌드 후 Bin으로 복사되고 Package.ps1이 가져간다

- 설정(Phase 20, 언리얼 Project Settings/Editor Preferences): 설정 = `FSettingsRegistry` 섹션(리플렉션으로 기술한 구조체 + 범위 + 파일, Core/Settings). 범위: `Project` → `<프로젝트>/Config/<Id>.json`(커밋), `EditorUser` → `%LOCALAPPDATA%/ProjectE/EditorPreferences/<Id>.json`, `ProjectUser` → `<Saved>/Config/<Id>.json`(상태, `bHidden`). **새 설정 항목은 구조체 필드 + 등록부(`ProjectSettings.cpp`/`EditorPreferences.cpp`)의 `.Property(...)`만** 추가하면 설정 창·저장에 나타난다(값 타입만: bool/int32/uint32/float/string/벡터, 4바이트 enum은 `.Enum({{이름, 표시}})` — JSON은 이름, `.Tooltip`, `.Range`, 에셋 경로는 `.AssetFilter`). 프로젝트 설정은 `FProjectSettings::Get()`(Info/Maps/Packaging/Physics/Network/Display)로 읽고 `.eproject`의 정체성(Name/EngineVersion/GameModule) 외 값을 새로 넣지 않는다(예전 필드는 `FProjectLegacyFields`로 읽어 옮김). 맵: 에디터 = `--scene` → 환경설정 "마지막 씬" → `GetEditorStartupMap()`, 런타임 = `Maps.GameDefaultMap`, 서버 = `GetServerDefaultMap()`. 물리/네트워크 값은 시작할 때(`FPhysicsSystem::Begin`, `FNetLaunchOptions::FromCommandLine`/`StartServer`/LAN 포트 0) 읽는다. 패키징 스크립트는 `Scripts/ProjectSettings.ps1`(`Read-ProjectSettings`, 같은 규칙)로 읽는다. 설정 창 `FSettingsWindow`(편집 메뉴, 값 바뀌면 `OnChanged` 즉시 + 조작 끝나면 저장, 자동 검증 `--open-settings project|editor [--settings-section <Id>]`), 값 위젯은 인스펙터와 공용 `FPropertyWidgets`. 자동 검증 실행은 개인 설정(마지막 씬, 자동 저장, 스냅 저장)을 쓰지 않는다

- 콘솔/CVar(Phase 38): 디버그·비교 토글은 `Core/Console`의 콘솔 변수(`TAutoConsoleVariable`, 이름 `r.X`, 도움말 필수)로 두고, 예전 명령줄 플래그는 `FConsoleVariableDesc::CommandLine` 별칭으로 남긴다. 일반 지정 `--cvar a=1,b=2`(여러 번), 명령 실행 `--exec "a;b"`, 검증 `--console-input <글자>`. 렌더러 토글은 `Renderer/RendererConsoleVariables.cpp`에 추가하고 `FSceneRenderer::ApplyConsoleVariables`가 프레임마다 읽는다(Init에서 명령줄 직접 파싱 금지, `r.TAA/SSAO/SSR`은 렌더러별 `FPostProcessSettings`와 AND). CVar 전역 객체는 DLL 밖으로 내보내지 않으므로 에디터·게임 모듈은 `FConsoleManager::Get().FindVariable`, UI 체크박스는 `ConsoleVariableWidgets`. 리소스 재생성이 필요한 변수는 `AddOnChanged`. 메인 스레드 전용, 이름 중복 금지. 기본 명령 `help`/`cvars`/`stat fps|gpu|none`, 런타임 \` 콘솔(`UI/UIConsoleOverlay`, 패키지에서는 프로젝트 설정 Console `EnableInPackagedGame`일 때만, 치트 플래그는 패키지에서 꺼짐)

- 프로파일링(Phase 38, Tracy v0.11.1, CMake `E_TRACY` 기본 ON): 존은 `Core/Profiling.h`의 `E_PROFILE_SCOPE/FUNCTION/FRAME/PLOT/THREAD_NAME`만 쓰고 Tracy 헤더를 직접 포함하지 않는다(예외 `Renderer/RenderProfiling.cpp` — TracyD3D12 GPU 존). 이름은 문자열 리터럴. 새 렌더 구간은 `ERenderTimer`에 추가하면 CPU/GPU 존이 자동으로 생긴다(`FD3D12GpuTimer` 칸 상한 32 — 2026-10-04 25칸). 연결 시에만 기록(ON_DEMAND, localhost), 개발 실행은 자동 시작, 패키지는 `--tracy`, 끄기 `--no-tracy`, 테스트는 시작 안 함. Tracy 버전을 바꾸면 뷰어 버전도 맞춘다
