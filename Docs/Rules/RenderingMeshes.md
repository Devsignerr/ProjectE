# 렌더링 메시·머티리얼 (스킨·스킨 캐시·블렌드·머티리얼 그래프·파티클·지형)

> CLAUDE.md에서 옮긴 상세 규칙이다. 이 영역의 코드·에셋을 고치기 전에 읽는다. 규칙을 바꾸거나 더할 때는 이 문서(또는 관련 머리 주석)를 고치고 CLAUDE.md 요약 줄도 맞춘다.

- 스켈레탈 애니메이션: 스킨 정점은 슬롯 1 스트림(`FSkinVertex`, 정적 메시 정점 형식은 불변), 본 팔레트 = `InverseBind * JointWorld`(프레임에 보이는 것만 이어 붙인 구조화 버퍼 t15 `SkinBones`, 인스턴스 `BoneOffset`으로 인덱싱 — `SkinnedMesh.hlsli`)로 바로 월드 공간이며 World는 항등. 팔레트는 `FSceneRenderer`가 프레임당 한 번 `FSkinnedMeshPalette::Build`로 올리고 섀도우/아웃라인이 공유한다. 팔레트는 **스킨 단위**(조인트 엔티티 목록 + 역바인드 행렬이 같은 프리미티브 엔티티들 = 같은 `BoneOffset`/`PrevBoneOffset`)이고 계산은 그룹마다 `FParallel::ParallelFor` — 가시성 판정 함수는 여러 스레드에서 불리므로 읽기 전용(규칙은 `SkinnedMeshPalette.h` 머리 주석) 재생 로직은 `FAnimationSystem`(Scene), 제어는 `Play/Stop/SetSpeed` API. 새 메시 패스를 추가하면 스킨 경로(`DrawSkinned` + 스킨 PSO — 스킨 캐시 변형 포함, 아래)도 함께 추가

- 스킨 캐시(`r.SkinCache`, 기본 끔 — CPU 병목인 Stress 1000유닛에서 GPU -0.4ms·CPU +0.3ms·메모리 +245MB로 프레임 손해, GPU 병목일 때 켠다, `Renderer/SkinCache.h` 머리 주석이 기준): 보이는 스킨 인스턴스(메시 인스턴스 목록에 든 것 = 팔레트 가시성 통과)를 프레임마다 계산 셰이더 `SkinCache.hlsl`로 **한 번** 스키닝해 풀 버퍼 하나(촘촘한 SoA 영역: 위치 float4(w = 가중치 합) 16B / 법선·탄젠트 32B / 이전 위치 16B = 정점당 64B + RT 대상만 FVertex 64B 영역, 영역 식 `SkinCacheMath::Get*Offset` ↔ `SkinnedMesh.hlsli` — 쓰기 대역폭이 비용의 대부분이라 AoS FVertex로 되돌리지 말 것. 자리는 메시 전체 정점(정점 번호 그대로)이고 스키닝은 인스턴스 LOD 이상이 쓰는 정점만 `FStaticMesh::GetLodVertexList`, 디스패치 = 메시·LOD·변형마다 하나, 배치 `SkinCacheMath::BuildLayout`(입력이 같으면 재사용) — 바꾸면 `SkinCache_*` 테스트)에 쓰고, 메시 패스(깊이 사전/메인/반투명/방향광·로컬 그림자/그래프 Masked 그림자)의 스킨 변형은 **디파인 `E_SKIN_CACHE`** 정점 셰이더(같은 엔트리 이름, 입력 레이아웃 = 슬롯 0만)가 t15를 `ByteAddressBuffer`로 읽는다(인스턴스 `SkinCacheVertex`/`SkinCacheCapacity` + `SV_VertexID` — 메시 그리기는 BaseVertexLocation 0이어야 한다). 그림자 LOD 바이어스는 더 거친 LOD만 쓰므로 "LOD L 이상 합집합" 목록이면 모든 패스가 덮인다 — **인스턴스 LOD보다 고운 LOD로 그리는 새 패스는 금지**(안 쓴 칸을 읽는다). `Prepare`는 `SelectLods` 뒤. 이전 위치는 이전 팔레트(`PrevBoneOffset`)로 같은 정점을 변환(이력 없으면 현재) — 팔레트 경로와 같은 식이라 화면이 **비트 동일**(Stress/PixelArt/Abilities/Training 확인). 스키닝 식을 바꾸면 `Mesh.hlsl` 팔레트 경로·`SkinCache.hlsl`·`RayTracingSkinning.hlsl`을 함께. **새 메시 패스**: 스킨 변형 VS에 `#ifdef E_SKIN_CACHE` 경로를 두고(`SkinnedMesh.hlsli` `LoadSkinCacheVertex/Position`), PSO 생성은 렌더러의 `bSkinCache`(FSceneRenderer가 Init 전·변경 시 맞추고 `ReloadShaders`)로 디파인·입력 레이아웃을 고르고, 루트 t15에는 `FSkinDrawSource::Address`를 묶고 패스 등록 때 `DeclareRead`(SrvNonPixel)를 부른다. 스킨 캐시 계산 패스는 첫 메시 패스(로컬 그림자) 전에 등록되고(람다는 등록 때 준비한 디스패치 목록만 기록 — 렌더 스레드 규칙), `Prepare`는 LOD 선택 뒤·`MeshInstances.Upload` 전(RT 켬/끔 판정은 그래서 수집 앞에서 한다). 레이 트레이싱 스킨 BLAS: LOD0이고 RT 스킨 거리 안 인스턴스는 캐시가 RT 정점 영역에 완전한 FVertex를 써 두고 RT는 갱신하는 모델만 그 범위를 자기 정점 풀로 `CopyBufferRegion`(“RT 스킨 정점 복사”), 나머지는 기존 RT 계산 스키닝(갱신 주기·풀 수명 그대로). 에디터 아웃라인은 팔레트 경로 그대로(팔레트는 항상 올린다). 메모리 = 보이는 스킨 인스턴스의 메시 정점 합 × 64B(+ RT 대상 × 64B, Stress 1000유닛 ≈ 400만 정점 ≈ 245MB, 줄이지 않음). 비용(Stress 1000, 720p): GPU 계산 ≈ 1.0ms로 사전/메인/그림자 VS 스키닝 ≈ 1.3ms를 대신해 GPU 합 −0.2~0.4ms(2000유닛 −0.8ms), CPU 배치 ≈ 0.2~0.3ms. 비교 `--no-skin-cache`(= `--cvar r.SkinCache=0`, 바꾸면 메시·그림자 파이프라인을 다시 만든다), GPU 구간 "스킨 캐시"

- 스킨 인스턴싱/컬링 보강(Phase 29): 스킨 메시도 (종류 1)·머티리얼·메시 키로 묶고(`ComputeSkinMatrix(BoneOffset, …)`, b4 CBV 없음), 깊이 패스는 `MakeDepthBatchKey`/`DrawDepthBatches`. 팔레트 가시성 = 메인 프러스텀 ∪ `FShadowRenderer::IntersectsCasterVolume` ∪ `FLocalLightRenderer::IntersectsShadowCaster`이므로 그림자 캐스터 볼륨은 `PrepareCascades`/`PrepareLights`로 팔레트보다 먼저 정한다. **새 그림자 패스를 추가하면 이 판정에도 넣는다**(빠지면 화면 밖 캐릭터 그림자가 사라짐). `IsCulled` 엔티티는 어떤 패스에도 넣지 않는다(확인 `--no-skin-culling`). 동적 업로드 버퍼는 차면 같은 프레임에 페이지를 덧붙이고(경고) 다음 Reset에 사용량 ×1.25로 합친다(상한 256MB, 큰 업로드 상한은 `GetMaxAllocation`, 복사 원본은 할당의 `Resource/ResourceOffset`, 확인 `--dynamic-buffer-kb N`). 파티클 컬링 경계 식은 `Renderer/ParticleBounds.h` — 입자를 더 멀리 보내는 모듈을 추가하면 `EstimateLocalRadius`와 `ParticleBoundsTests`도 고친다. 화면 밖 GPU 이미터의 계산 미루기 규칙은 `ParticleRenderer.h` 머리 주석, 이미터 `bFixedBounds`가 있으면 그것을 쓴다(`--no-particle-culling`). LOD는 `LodMath::SelectLodWithHysteresis`(기본 ±10%, `--lod-hysteresis`), 이전 LOD는 렌더러가 엔티티별로 보관

- 머티리얼 블렌드 모드/인스턴스(Phase 36): `.emat` `BlendMode` = Opaque/Masked/Translucent/Additive(`EMaterialBlendMode`, 번호는 끝에만 추가, JSON은 이름), `AlphaCutoff`, `TwoSided`, `Parent`(이 파일 폴더 기준 상대 경로 — 파일에 적힌 키만 덮어씀, 이름은 상속 안 함). 해석은 `FMaterialAsset::Resolve`만(체인 최대 16, 순환·부모 없음은 오류 로그 후 읽은 데까지, 부모 텍스처는 자식 폴더 기준으로 재작성 — 바꾸면 `MaterialTests`). 코드에서 머티리얼을 고칠 때는 `FMaterial`을 직접 고치지 말고 `ApplyMaterialAsset`(캐시된 자식 `ParentChain`도 다시 해석). Masked = 베이스 알파(텍스처 × 정점 색 × 팩터) < 컷오프면 버림 — `PSMainMasked`/`PSPrepassMasked`/`ShadowMaskedPS`가 같은 식이라 함께 고친다. 양면 = CULL_NONE + 뒷면은 `SV_IsFrontFace`로 셰이딩·기하·화면 법선을 뒤집는다. 메시 PSO 변형 = 묶음 키 Pipeline 3비트(`MaterialRender::MakeVariant`: bit0 Masked/Additive, bit1 양면, bit2 스킨 — 스킨이 최상위여야 오클루전 1단계가 맞음), 키는 `MakeMainBatchKey`/`MakeDepthBatchKey`(그림자는 Masked만 머티리얼별). `FMeshInstance`는 머티리얼 상태 사본(`CopyMaterialState` — Gather/`AddExternal`이 채움), 그림자 패스는 `CastsShadow()`(반투명 제외). 반투명/가산은 사전 패스·그림자·오클루전에 넣지 않고 안개 적용 뒤·파티클 전 `DrawTranslucentBatches`가 먼 것부터(깊이 쓰기 없음, SSR/SSAO/데칼 미사용, 안개 `EvaluateFog` 직접 b6/t23/s3, 출력 알파 = TAA 반응형 마스크). **새 메시 패스는 변형 8개와 Masked clip을 함께 지원**한다. 쿠킹 모델에 머티리얼 상태가 들어가므로 바꾸면 `ModelVersion`. glTF `alphaMode/alphaCutoff/doubleSided` 반영(FBX는 미반영)

- 머티리얼 그래프(Phase 49 사이드): `.emat` `"Graph"` + `"Parameters"`가 있으면 그래프가 표면을 만든다. 형식·타입 규칙(float1만 확장, 출력 핀·UV만 자르기)·컴파일 규칙(전체 순환 검사, 출력에서 닿는 노드만, 공통식 재사용, 지역 변수 = 방문 순서 번호 → 결정적 해시, 레이아웃 = 쓰인 파라미터 선언 순서: 벡터 → 스칼라 4개 묶음 → 텍스처)은 `Renderer/MaterialGraph.h` 머리 주석이 기준. 그래프 없는 머티리얼은 `MaterialDefault.hlsli`(기존 식 — 바꾸면 기존 화면이 바뀐다). 인스턴스는 `Parameters` 값만 덮어쓰고(이름) 그래프는 체인 맨 위 것. **새 노드**는 `MaterialGraphCompiler.cpp` 노드 표(`GetNodeTable`)에 넣고 `MaterialGraphTests`(`AllNodeTypesCompile`) + `MaterialGraphShaderTests`(DXC)에도 연결, 공용 HLSL 식은 `MaterialCommon.hlsli`. Type 이름은 JSON에 저장되므로 바꾸지 않는다. 머티리얼 셰이더에서 ddx/ddy와 `.Sample` 직접 사용 금지 — 텍스처는 `MATERIAL_SAMPLE`만(래스터 메시 패스는 `Mesh.hlsl`이 `E_MATERIAL_MIP_BIAS MaterialMipBias`를 정의해 TAAU 밉 바이어스 적용). 모든 머티리얼은 `EvaluateMaterial(FMaterialPixelInputs, out FMaterialSurface)` 하나(`MaterialCommon.hlsli` 머리 주석이 기준) — **새 메시 패스**는 `Mesh.hlsl`처럼 `MaterialCommon.hlsli` → `#ifdef E_MATERIAL_GRAPH` 생성 파일 / `MaterialDefault.hlsli`를 include하고, Masked clip = `OpacityMask - E_MATERIAL_ALPHA_CUTOFF`, 탄젠트 노멀은 `MaterialTangentToWorld`, Metallic saturate. 그래프 변형 셰이더는 `MaterialRender::MakeGraphShaderDesc`(디파인 `E_MATERIAL_GRAPH` + 가상 파일)로 얻고 `GetGraphShaderDescs`(쿠킹 목록)에도 더한다. PSO는 셰이더 해시별 캐시, 정점 셰이더는 기본 바이트코드(사전 패스 EQUAL 유지). 바인딩: b2 = `MaterialRender::UploadMaterialConstants`(`FMaterialGraphHeader` + `MaterialParams[]`), 공간 2 무제한 테이블 = `FMaterial::TextureTable`(`max(TextureCount, 5)`칸, 최대 `MaterialTextureMax` 16) — 메시 루트 #24, 그림자 루트 #6/#7 + s1. **레이 트레이싱/계산(DXR 히트, DDGI)**은 `MATERIAL_SAMPLE`을 SampleLevel/SampleGrad로 먼저 정의하고 `E_MATERIAL_CUSTOM_RESOURCES` + `E_MATERIAL_HEADER/PARAM(i)/TEXTURE(i)`로 로컬 루트 시그니처나 바인드리스에 연결한 뒤 무게중심 보간으로 입력을 채워 `EvaluateMaterial`을 부른다(any-hit에서 OpacityMask로 IgnoreHit). 생성 소스는 `FMaterial::Shader->Hlsl`, 해시가 변형 키. `FShaderCompileDesc::VirtualFiles`(이름 + 내용)는 `#include`와 진입 파일 모두에 쓰이고 내용 해시가 캐시 키·쿠킹 파일명에 들어간다. `ProjectECook`이 프로젝트 `.emat` 전부를 쿠킹(패키지는 DXC 없이). 그래프 컴파일 오류면 이전 셰이더 유지, PSO 실패면 기본 머티리얼. 에디터는 `.emat` 변경을 `FResourceManager::ReloadMaterialFile`로 핫 리로드.

- 파티클 (나이아가라식): 에셋은 `.eparticle` v2(`FParticleSystemAsset`, Scene 모듈) = 이미터 목록, 이미터마다 단계 3개(이미터 갱신/입자 생성/입자 갱신) 모듈 목록 + 렌더러 목록. 모듈 입력은 `FParticleValue`(상수/무작위/곡선). 버전 없는 이전 형식은 `FromJsonString`이 변환한다. 인스턴스는 `FParticleSystemComponent`(Asset 경로) + 비직렬화 `Runtime`(이미터별 `FParticleEmitterInstance`). 에셋은 `FResourceManager::LoadParticleSystem` 경로 캐시로 공유되고 `FSceneAssetResolver::ResolveParticles`가 경로 변경을 반영한다. 갱신 순서: 애니메이션 → `UpdateTransforms` → `ResolveParticles` → `FParticleSystem::Update`(CPU 입자 적분 / GPU는 계산 요청만 쌓음) → 렌더(`FParticleRenderer::Simulate`로 GPU 계산 → HDR 패스 불투명 메시 뒤 `Render`). **모듈 추가/변경 규칙**: `EParticleModuleType` 번호는 셰이더와 공유하므로 끝에만 추가하고, `Particles.cpp`의 모듈 정보 표·CPU 식과 `ParticleSimulate.hlsl`(+ `ParticleCommon.hlsli`의 해시/노이즈/모양)을 **같은 식으로 함께** 고친다. 입력 순서 = 난수 흐름 번호이므로 기존 입력 사이에 끼워 넣지 말 것. 입자 구조를 바꾸면 `FParticle`/`FParticleGpuData`(ShaderTypes.h)/`FParticleData`(hlsli)를 함께 맞춘다

- 지형/식생(Phase 34): 지형은 엔티티 위치만 따른다(회전/스케일 무시, 위치 = 지형 가운데, 16비트 값 32768 = 위치 Z). 셀 대각선은 (0,0)-(1,1)이며 수학·렌더·충돌이 같은 면을 쓴다. 지형/폴리지 데이터를 바꾸면 반드시 `MarkChanged`(폴리지는 `MarkChanged(타입)`). Undo는 스트로크 끝에만 기록 + `EditRevision` 갱신 + `MarkEdited`(끄는 도중 `MarkEdited` 금지). Jolt 높이장은 회전 (0.5,0.5,0.5,0.5), 표본은 엔진 격자의 전치. `Terrain.hlsl`은 `Mesh.hlsl`을 include하므로 조명 함수를 바꾸면 함께 확인한다. 새 그림자 캐스터 종류는 `FShadowCasterHook`으로 붙인다. 폴리지는 `FMeshInstanceList::AddExternal`로 넣고(Entity에 NullEntity 금지), 그림자 패스는 `bCastShadow`를 존중하며, LOD를 직접 고르면 `bFixedLod`를 켠다. 알파 테스트가 없으므로 풀은 실제 기하 메시. 뷰포트 브러시 표시는 `ToolOverlay` 훅
